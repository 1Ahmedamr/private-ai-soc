4.1 src/correlation/timeline.py (NEW)
-----------------------------------------------------------
Builds a chronological attack timeline for one correlated host.

Works on session-dict form of incidents and host summaries (plain dicts),
so it is trivially testable and has no Flask dependency.

Honesty note: entries are ordered by when each INCIDENT's detection
window began. That shows observed sequence, not proven causation.
All timestamps normalized to UTC for display.

Functions:
- _parse(ts) → datetime UTC
- _fmt(dt) → "YYYY-MM-DD HH:MM:SS UTC"
- _human(seconds) → "Xh Xm Xs"
- _sev(value) → severity string
- _tactics_for(techniques) → list of tactics from MITRE
- build_host_timeline(host_summary, incidents) → dict with ordered entries

4.2 src/mitre/naming.py (NEW)
-----------------------------------------------------------
One canonical spelling for ATT&CK tactic names, whatever the source wrote.

Handles: "command-and-control", "defense_evasion", "Command And Control"
Matches ATT&CK's own style: "Command and Control", "Defense Evasion"

Functions:
- format_tactic(raw) → canonical tactic name

4.3 src/webapp/analysis_store.py (NEW)
