- parse_zeek_conn_logs(raw_events) → batch version

Functions:
- parse_suricata_alert(raw_event) → NormalizedEvent
  Severity mapping:
    "ET INFO" or "SURICATA" → Severity.LOW (never HIGH)
    "ET MALWARE" or "ET TROJAN" → Severity.HIGH (not confirmed compromise)

  Timestamps: parsed via dateutil.parser.isoparse, converted to UTC
  event_id = signature name (e.g. "ET PROTOCOL-OTHER")
- parse_suricata_alerts(raw_events) → batch version
